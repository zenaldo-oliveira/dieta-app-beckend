# 🥗 Dieta App Backend

API desenvolvida para gerenciamento de planos alimentares, usuários e acompanhamento nutricional.

## 🚀 Tecnologias

- Node.js
- Express
- JavaScript
- MongoDB
- Mongoose

## 📁 Estrutura do Projeto

```
src/
├── controllers/
├── models/
├── routes/
├── services/
└── app.js
```

## ⚙️ Instalação

Clone o projeto:

```bash
git clone https://github.com/zenaldo-oliveira/dieta-app-backend.git
```

Entre na pasta:

```bash
cd dieta-app-backend
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm start
```

## 🔑 Variáveis de Ambiente

Crie um arquivo `.env`:

```env
PORT=3000
MONGO_URI=sua_url_mongodb
JWT_SECRET=sua_chave_secreta
```

## 📌 Funcionalidades

- Cadastro de usuários
- Login com autenticação
- Gerenciamento de dietas
- Controle de refeições
- API REST
